# RdpCenter

Готовые файлы RdpCenter - менеджера RDP-серверов для Windows с чистым микрофоном и звуком сеанса через Tailscale.

Скачать: **Releases** → последняя версия.

- `RdpCenter.exe` - клиент для Windows 10/11, запускается без установки.
- `RdpCenter-Server.exe` - агент для сервера: запустить двойным щелчком и подтвердить запрос администратора.

Клиент обновляется в «Настройки → Общие → Проверить обновления», агент на сервере обновляется сам.
