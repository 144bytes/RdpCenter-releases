# RdpCenter

Менеджер RDP-серверов с чистым микрофоном и звуком сеанса через Tailscale. Программа для Windows.

## Установка

На сервере и на компьютере клиента должен быть установлен [Tailscale](https://tailscale.com/download).

**Сервер** (Windows с включённым RDP):

1. Скачайте `RdpCenter-Server.exe` из последнего [релиза](../../releases/latest).
2. Запустите его двойным щелчком и подтвердите запрос администратора. Программа сама поставит
   звуковые драйверы, создаст службу `RdpCenter` и откроет порт только для Tailscale.

**Клиент** (Windows 10/11):

1. Скачайте `RdpCenter.exe` из последнего [релиза](../../releases/latest) и запустите, установка не нужна.
2. Нажмите «Добавить сервер» и укажите адрес Tailscale, логин и пароль Windows.
3. Чтобы передавать голос своим каналом, подключайтесь с включённым микрофоном.

Обновления клиента устанавливаются из программы: «Настройки → Общие → Проверить обновления».
Сервер обновляется сам.

Удалить сервер: `RdpCenter-Server.exe uninstall` от администратора.
